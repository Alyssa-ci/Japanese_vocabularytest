# 日本語語彙力診断 (Japanese Vocabulary Assessment)

一个科学、高效的日语词汇能力测评网站，帮助用户快速了解自己的日语词汇水平（N5-N1）。

## 功能特点

- 📊 **科学测评**：基于JLPT标准，采用自适应算法
- ⚡ **快速高效**：只需15分钟，获取详细报告
- 🎯 **个性建议**：针对薄弱项推荐学习资源
- 📈 **可视化报告**：雷达图展示各级别掌握度
- 🎨 **现代UI**：美观的界面设计和流畅的动画效果

## 技术栈

- **框架**：Next.js 14 (App Router)
- **语言**：TypeScript
- **样式**：Tailwind CSS
- **动画**：Framer Motion
- **图表**：Recharts

## 项目结构

```
├── app/
│   ├── page.tsx              # 首页/引导页
│   ├── quiz/
│   │   ├── intro/            # 测评说明页
│   │   ├── question/         # 答题页面
│   │   └── processing/       # 测评完成/加载页
│   └── report/
│       └── [reportId]/       # 测评报告页
├── lib/
│   ├── types.ts              # TypeScript 类型定义

│   └── report-generator.ts   # 报告生成逻辑
└── components/               # 可复用组件（可选）
```

## 安装和运行

1. 安装依赖：
```bash
npm install
```

2. 启动开发服务器：
```bash
npm run dev
```

3. 在浏览器中打开 [http://localhost:3000](http://localhost:3000)

## 页面说明

### 1. 首页 (/)
- 展示网站核心价值
- 动态展示N5-N1级别
- 测评介绍卡片
- 开始测评入口

### 2. 测评说明页 (/quiz/intro)
- 测评规则说明
- 可选设置（音效、解析显示）
- 用户信息收集
- 开始答题按钮

### 3. 答题页面 (/quiz/question)
- 自适应题目难度
- 实时进度显示
- 答题反馈
- 跳过功能（限制次数）

### 4. 测评完成页 (/quiz/processing)
- 加载动画
- 分析过程展示
- 自动生成报告

### 5. 测评报告页 (/report/[reportId])
- 综合等级展示
- 雷达图可视化
- 详细分析（强弱项）
- 个性化学习建议
- 资源推荐
- 社交分享

## 自适应算法

系统会根据用户的答题情况动态调整题目难度：
- 正确率 ≥ 80%：提升难度
- 正确率 < 40%：降低难度
- 正确率在 40%-80%：保持当前难度

## 数据存储

目前使用 localStorage 存储：

- 答题记录
- 题目数据
- 生成的报告
